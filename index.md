Un libro para aprender SageMath viendo cómo piensa cada programa: línea a línea, con la memoria a la vista. Es el cuarto de la colección, después de los de Python, R y Julia, y está hecho con el mismo método. Cada idea parte de una situación cotidiana, se construye con código y se comprueba visualizando la ejecución.

SageMath, o Sage a secas, es un sistema de matemáticas libre. Por fuera se escribe casi como Python. Por dentro reúne cientos de programas libres especializados que trabajan juntos: uno factoriza, otro integra, otro guarda los números enormes. Este libro cuenta las dos cosas: cómo se le pide algo a Sage y quién lo hace por dentro.

## Un libro, dos rutas

Como los programas del IB con su nivel medio y su nivel superior, este libro tiene **dos rutas** que conviven en las mismas páginas.

- La **ruta base** es la que sigue todo el mundo: la idea con un ejemplo hecho, el código visualizado paso a paso y los ejercicios. Sirve para clase y para aprender solo.
- Los apartados **A fondo** llevan una cápsula negra. Cuentan cómo funciona Sage por dentro y cómo se trabaja con él como profesional. Se pueden saltar sin perder el hilo.
